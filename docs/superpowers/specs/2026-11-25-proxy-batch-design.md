# 批量代理导入短设计

来源：协调者批准的 `pc-proxy-batch-and-engine-20261125/design.md`。目标是先交付批量静态代理导入，不更换桥接内核或发布版本。

沿用代理池抽屉，新增“批量导入”：用户点击粘贴多行或选择 UTF-8 TXT 后立即产生逐行预览，选择默认协议后可重新解析，确认才保存，返回/取消不保存。沿用当前粘贴按钮和系统文件选择模式；不新增多行编辑器，不将含密原文显示在界面。预览只显示规范化端点、是否认证、行号与静态错误原因。

支持 HTTP/HTTPS/SOCKS5 URL（含现有 socks/socks5h 别名）、host:port、主机:端口:用户名:密码；IPv6 使用方括号，四段式密码中的冒号与内部/末尾空格按原字符保留，URL 认证沿用现有百分号校验。空行/BOM/CRLF 可用。默认 HTTP，与现有新增编辑器一致。最多 1 MiB、1000 个非空条目，每行最多 16384 字节，超限明确拒绝，不截断。

去重以规范化协议/host/port/用户名/密码构成的规范 URL 的 SHA-256 为键，不输出键或认证。预览与确认都检查当前代理池；已保存凭据不可读取时失败关闭，避免误判重复。只追加新 UUID/凭据 revision，不覆盖条目、绑定或账号 generation。先保存新凭据，再原子保存一次 workspace；失败清除本批暂存版本，原列表保持不变。

比较：逐条调用原 save 实现简单但可产生部分成功，故采用一个批次事务；新增订阅框架或外部引擎与本功能无关。本次不修改保护存储、迁移 v1、单条编辑、CI、版本号或账号路由，不自动测网络。

验证遵守 AGENTS：一次必要编译/构建及最小直接核对，不新增测试用例或框架，不跑旧诊断矩阵。无安全后台原生运行条件则明确未测，不读取真实数据或剪贴板。
